# @aifuxi/semi-icons-vue

从固定 Semi Design `v2.102.0` 资源生成的稳定版 Vue 3 图标组件。

> 本包是独立 Vue 复刻项目的一部分，不是 Semi Design 官方 Vue 版本，也不是 `@douyinfe/semi-icons` 的官方适配包。

## 安装与使用

```bash
pnpm add @aifuxi/semi-icons-vue@next
```

```ts
import { IconHome } from '@aifuxi/semi-icons-vue';
import IconHomeDirect from '@aifuxi/semi-icons-vue/icons/IconHome';
```

本包为 ESM-only，要求 Vue `>=3.5.0`，支持根入口、`Icon` 基座和逐图标子路径。

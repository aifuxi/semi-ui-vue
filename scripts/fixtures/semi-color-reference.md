# 颜色生成器参考数据

`semi-color-reference.json` 是颜色生成算法的冻结验收数据，不是默认主题的色值来源。默认主题仍由只读 Semi `v2.102.0` vendor 编译。

## 来源与生成方式

- 采集日期：2026-11-07。
- 官方 DSM 发布脚本：<https://semi.design/dsm/assets/index-8031b4fc.js>。
- 脚本 SHA-256：`18fb07d290c0fa19e3dd2b6c50eec7830f518e7af15839bb30dd9bea04dd8b91`。
- 参考颜色运算依赖：`chroma-js@2.6.0`，读取 npm 发布物 `dist/chroma.cjs`；该文件 SHA-256 为 `327c54368c346b552975684f8e61633145db1980dc15fe020abdb110b7af60f4`。
- 在无 DOM 的隔离 JavaScript VM 中载入参考脚本的色轮数据、生成函数及其必要依赖，通过脚本的 `Jl(color, { mode })` 和 `Jl(color, { mode, dir: 'wheel' })` 得到预期结果。
- 样本输入及输出由参考脚本独立计算，未调用本项目的颜色生成器。测试运行只读取冻结 JSON，不联网，也不执行或发布参考实现。

## 数据结构

- `reference`：来源、摘要和生成方式，供人工复核数据版本。
- `scales`：61 组 `{ color, light, dark }`；每个模式包含十个小写六位 HEX，下标对应 Semi `0…9`。
- `palettes`：50 组 `{ color, light, dark }`；每个模式包含十七组命名色阶，其中 `brand` 独立于 `blue`，其余为十六组基础色盘。

样本覆盖初始色轮锚点，色相 `20/30/48/80/200/260°` 及其相邻量化值（采样偏移 ±0.3°，确保跨过 RGB 整数取整边界），纯红绿蓝、互补色，极低/极高明度、饱和度 `0.1` 与明度 `0.8` 分段两侧及精确边界、低饱和度、常用品牌色，以及无色相的黑白灰。整盘数据排除无色相输入，因为上游此时会产生 NaN 色轮退化，本项目按公开契约拒绝该输入。

相等判断采用完整 HEX 字符串相等，等价于逐 RGB 整数通道完全一致。任何默认主题差异不得通过更新该文件处理；任何参考算法升级都须重新说明版本、来源及公开契约影响。

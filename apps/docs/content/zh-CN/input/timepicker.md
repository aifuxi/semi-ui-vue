### 不同的 Format 格式

TimePicker 浮层中的列会随着 `format` 变化，当略去 `format` 中的某部分时，浮层中对应的列也会消失。

NOTE: `format` 遵循 date-fns 的 `format` 格式。 https://date-fns.org/v2.0.0/docs/format

### 12 小时制

12 小时制的时间选择器，默认的 `format` 为 `h:mm:ss a`，传入的 `format` 格式必须在 [dateFns 日期格式](https://date-fns.org/v2.0.0/docs/format)范围之内。

> 例如默认的 12 小时制格式串为：`a h:mm:ss`，如果传入 `A h:mm:ss` 则会导致无法正确格式化。

<DemoBlock id="zh-CN-input-timepicker-9" title="12 小时制" kind="live" />

### 时间范围

传入 type="timeRange" 开启时间范围选择。

<DemoBlock id="zh-CN-input-timepicker-10" title="时间范围" kind="live" />

### Range 模式下分别禁用左右面板（disabledTime）

当 `type="timeRange"` 时，你可以通过 `disabledTime(value, panelType)` 对左右面板分别应用不同的禁用规则。

- `value`：单选模式为 `Date`；range 模式为 `Date[]`（可能为空/长度为 1/2）
- `panelType`：`'left' | 'right'`，分别代表开始/结束面板

下面示例实现：选择开始时间后，右侧结束时间面板会禁用早于开始时间的选项。

<DemoBlock id="zh-CN-input-timepicker-11" title="Range 模式下分别禁用左右面板（disabledTime）" kind="live" />

## API 参考

### Vue 契约

> 以下内容以 `packages/ui/src/time-picker/types.ts`、`packages/ui/src/time-picker/index.ts` 的公开类型为准。

- `v-model` 对应 `modelValue`，同时支持 `v-model:value`。
- `v-model:open` 对应面板展开状态。

#### Vue 实例方法

**TimePicker ref**

| 方法    | 签名          | 说明           |
| ------- | ------------- | -------------- |
| `open`  | () =&gt; void | 展开面板       |
| `close` | () =&gt; void | 关闭面板       |
| `focus` | () =&gt; void | 聚焦输入框     |
| `blur`  | () =&gt; void | 移除输入框焦点 |

## 文案规范

- 时间选择器至少包括时和分，如：11:30，它在本地化过程中，可以适应为12小时制或者24小时制
- 当选择12小时制，需要和AM/PM一起搭配使用

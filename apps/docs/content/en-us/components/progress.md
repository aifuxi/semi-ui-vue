### Standard progress bar

Use `stroke` Property to control the filling color of the progress bar  
Use `percent` Property to control completed progress  
Use `size` Property control progress bar size  
Use `aria-label` Property to explain the specific role  
If the preset size is not satisfied, You can pass height to customize the height of the progress bar through `style` property.

## API Reference

| Property                           | Description                                                                    | Type                              | Default                          |
| ---------------------------------- | ------------------------------------------------------------------------------ | --------------------------------- | -------------------------------- |
| `ariaLabel / aria-label`           | Accessible name for the progress bar                                           | `string`                          | `—`                              |
| `ariaLabelledby / aria-labelledby` | IDs of labeling elements, separated by spaces                                  | `string`                          | `—`                              |
| `ariaValuetext / aria-valuetext`   | Textual alternative to the numeric value                                       | `string`                          | `—`                              |
| `class / className`                | Style class                                                                    | `HTMLAttributes["class"]`         | `—`                              |
| `direction`                        | Line direction: horizontal, vertical                                           | `ProgressDirection`               | `horizontal`                     |
| `format`                           | Format the current animated percentage; also available as a scoped format slot | `(percent: number) => VNodeChild` | `percent => percent + '%'`       |
| `id`                               | Element ID                                                                     | `string`                          | `—`                              |
| `motion`                           | Controls numeric animation; false updates the value immediately                | `ProgressMotion`                  | `true`                           |
| `orbitStroke`                      | Track fill color                                                               | `string`                          | `CSS: var(--semi-color-fill-0)`  |
| `percent`                          | Percentage, displayed within 0–100; do not pass NaN                            | `number`                          | `0`                              |
| `showInfo`                         | Show text inside the circle or beside the line                                 | `boolean`                         | `false`                          |
| `size`                             | default; small applies to circle; large applies to line                        | `ProgressSize`                    | `default`                        |
| `stroke`                           | Progress color; stops accept CSS colors and Semi palette names                 | `string / ProgressStrokePoint[]`  | `CSS: var(--semi-color-success)` |
| `strokeGradient`                   | Interpolate between color stops; requires a stroke array                       | `boolean`                         | `false`                          |
| `strokeLinecap`                    | Circle end caps: round or square                                               | `ProgressStrokeLinecap`           | `round`                          |
| `strokeWidth`                      | Circle stroke width                                                            | `number`                          | `4`                              |
| `style`                            | Wrapper style; can customize line height or width                              | `StyleValue`                      | `—`                              |
| `type`                             | line, circle                                                                   | `ProgressType`                    | `line`                           |
| `width`                            | Circle diameter                                                                | `number`                          | `default: 72; small: 24`         |

The `#format="{ percent }"` scoped slot takes precedence over the `format` prop. `ProgressStrokePoint` contains `{ percent: number; color: string }`. Progress is controlled with `:percent`; it does not expose `v-model` or a change event.

## Accessibility

### ARIA

- Progress has a `progressbar` role to indicate that it is a progress bar component.
- Progress will automatically set `aria-valuenow` as the progress percentage (`percent`) passed to the component to ensure that the screen reader can get the correct percentage value. In addition, Progress supports incoming `aria-valuetext`. When you pass in, according to W3C specifications, `aria-valuetext` will be used and consumed by screen readers instead of `aria-valuenow`
- Progress support `aria-label`, `aria-labelledby`
  - When there is a description element about the role of Progress outside of Progress, you can explicitly specify that the id of certain elements is the label of Progress through `aria-labelledby`
  - Otherwise, you should use aria-label to explain the specific meaning of the value represented by Progress

```vue
<p id="progressbar-label">Disk usage</p>
<Progress aria-labelledby="progressbar-label" :percent="80" />
<Progress aria-label="File download" :percent="80" />
<Progress aria-label="Disk usage" :percent="80" aria-valuetext="Step 2: Copying files…" />
```

## Content Guidelines

- If the progress bar process is complicated, or there is a long waiting time, you can use the help text to explain. This lets the user know what progress is happening.

## FAQ

**Why is circle text missing?** `showInfo` defaults to false and `size="small"` suppresses circle text.

**Is strokeGradient a spatial gradient?** It interpolates one progress color between the supplied percentage stops as percent changes.

**How do I change line thickness?** Use `size="large"` or a height style for horizontal lines; `strokeWidth` controls circles.

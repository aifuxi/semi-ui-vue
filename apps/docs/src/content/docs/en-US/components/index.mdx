The six-component reference batch validates documentation patterns for regular interaction, portals, complex data, independently published assets, and Worker-backed components. Every demo consumes public `@aifuxi/*` entries, and each preview displays source from the same Vue SFC.

| Component  | Representative capability                   | Documentation                          |
| ---------- | ------------------------------------------- | -------------------------------------- |
| Button     | Regular interaction and compound components | [Open](/en-us/components/button/)      |
| Select     | Input, search, and Portal                   | [Open](/en-us/components/select/)      |
| Modal      | Portal, focus, and Promise                  | [Open](/en-us/components/modal/)       |
| Table      | Generics, complex data, and scrolling       | [Open](/en-us/components/table/)       |
| Icon       | Independent asset package and accessibility | [Open](/en-us/components/icon/)        |
| JsonViewer | Worker, SSR, and editing                    | [Open](/en-us/components/json-viewer/) |

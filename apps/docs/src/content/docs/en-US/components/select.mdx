Use `optionList` for `{ value, label, disabled }[]`. Prefer `v-model` for controlled state; `value` / `update:value` remains available for incremental React migrations. The popup teleports to `document.body` by default; use `getPopupContainer` for a local scrolling container.

## Slots and React to Vue

`prefix`, `insetLabel`, `suffix`, `arrowIcon`, `clearIcon`, `emptyContent`, `outerTop`, `innerTop`, `innerBottom`, and `outerBottom` are named slots. `option`, `selectedItem`, `createItem`, and `trigger` are scoped slots.

| React                               | Vue                                  |
| ----------------------------------- | ------------------------------------ |
| `value` + `onChange`                | `v-model`                            |
| `Select.Option` / `Select.OptGroup` | `SelectOption` / `SelectOptionGroup` |
| `renderOptionItem`                  | `#option`                            |
| `renderSelectedItem`                | `#selectedItem`                      |
| `triggerRender`                     | `#trigger`                           |
| ReactNode extension points          | Matching named slots                 |

## Keyboard and accessibility

The trigger uses combobox/listbox semantics. Enter, Space, ArrowUp/ArrowDown, Home, End, Escape, and Tab follow the pinned reference. Provide a stable `insetLabelId` for an inset label.

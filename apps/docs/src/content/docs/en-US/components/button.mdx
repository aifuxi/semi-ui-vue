Loading blocks pointer interaction. Disabled takes precedence when both states are present. Icon-only buttons need an accessible name through `aria-label` or visible text. `htmlType` defaults to `button`; use `submit` only for an intentional form submission.

## React to Vue

| React                         | Vue                                                          |
| ----------------------------- | ------------------------------------------------------------ |
| `children`                    | Default slot                                                 |
| `icon={<Icon />}`             | `#icon` slot                                                 |
| `className` / `style`         | Native `class` / `style` attrs                               |
| `contentClassName`            | `contentClass`                                               |
| `onClick` and other callbacks | Vue events such as `@click`                                  |
| React ref                     | Vue template ref; focus usually targets the root DOM element |

`optionList` 可直接传入 `{ value, label, disabled }[]`。受控场景优先使用 `v-model`；组件也保留 `value` / `update:value`，便于逐步迁移 React 状态。弹层默认 Teleport 到 `document.body`，需要局部滚动容器时使用 `getPopupContainer`。

## 插槽与 React → Vue

`prefix`、`insetLabel`、`suffix`、`arrowIcon`、`clearIcon`、`emptyContent`、`outerTop`、`innerTop`、`innerBottom`、`outerBottom` 是具名插槽；`option`、`selectedItem`、`createItem`、`trigger` 是 scoped slot。

| React                               | Vue                                  |
| ----------------------------------- | ------------------------------------ |
| `value` + `onChange`                | `v-model`                            |
| `Select.Option` / `Select.OptGroup` | `SelectOption` / `SelectOptionGroup` |
| `renderOptionItem`                  | `#option`                            |
| `renderSelectedItem`                | `#selectedItem`                      |
| `triggerRender`                     | `#trigger`                           |
| ReactNode 扩展位                    | 对应具名 slot                        |

## 键盘与可访问性

触发器使用 combobox/listbox 语义。Enter、Space、ArrowUp/ArrowDown、Home、End、Escape 与 Tab 的行为与固定基线一致；使用内嵌标签时应提供稳定的 `insetLabelId`。

## 自定义图标与迁移

默认导出的 `Icon` 可通过默认 slot 接收自定义 SVG。React 的 `<Icon svg={<CustomIcon />} />` 对应 Vue 的 `<Icon><CustomIcon /></Icon>`；`className` 改为原生 `class`。仅装饰用途的图标应隐藏于辅助技术，独立图标按钮必须由按钮提供可访问名称。

# Theme Studio 全界面样式联动核对

日期：2026-11-08。

## 问题与根因

用户要求在气泡与弹层之外，继续核对所有现有组件及工作台界面，确保编辑全局样式后同步更新。

核对范围为顶部导航、分类栏、变量列表、检查器、主题表单，以及总览中的 Button、Input、Select、Checkbox、Radio、Switch、Tag、Progress、Table、Card，并保留已完成的浮层检查。

- 工作台虽然已有全局颜色边界，字号、字重、行高、圆角、间距和状态提示阴影仍包含固定值；字体也只在祖先声明，子边界重新定义变量不会重新计算已经继承的 font-family。
- 迭鹿生成的排版预设把 Select、Checkbox、Radio、Table、Tag 等默认文字固定为 `14px/20px` 或 `12px/16px`，应用预设后会遮住后续基础字号、行高与字重编辑。
- Checkbox 的可见标签和 Card 正文使用各自固定的行高回退；独立前景映射遗漏了复选/单选标签、下拉选项和 Card 标题。

## 实现

- 在工作台根重新声明字体；自有 UI 统一引用公开字号、字重、行高及圆角角色。紧凑文字和边角以相对偏移保留现有默认外观，不强制不同角色使用同一数值。
- 工作台布局引用现有 `--studio-spacing-*`。非标准间距保留相对偏移，允许的 0px 边界不会产生负 padding/gap；控件高度和结构尺寸仍使用原 API。补齐复选/单选的共享文字间距绑定。
- 状态提示使用 elevated 阴影角色；色样数字上的固定黑白衬底继续用于读取任意色值，不跟随主题而改变色样内容。
- 生成排版预设的默认字符串改为语义引用，保持默认尺度，同时让全局编辑继续作用于真实组件。输入框对齐行高继续服从固定控件高度。补齐 Checkbox 标签、Card 正文行高以及独立前景的实际消费节点。
- 版本 1 导入文件仅升级与旧生成预设完全一致的字符串；其他手工 font 值、显式组件覆盖和独立局部主题保留。在线规则与 CSS 导出共用同一套引用和绑定。

## 验证

- 新增 6 项实际页面检查：默认/预设两种起点的全局排版；颜色与状态；预设前景；圆角/间距/阴影；旧文件升级与手工排版保留。均通过 UI 编辑，没有直接写入被测 DOM 样式。
- 首轮完整检查为 65 项通过、3 项失败：两条旧阴影用例仍按已替换的 Tooltip 查找交互气泡，一条新增检查要求页面未展示的 Progress 文字。更新为真实 Popover 及实际展示节点，阴影几何与背景断言保持要求；定向 7 项通过。
- 最终 `pnpm test:theme-studio`：68 项全部通过，约 37.2 秒，完整 Chromium 新 headless、3 workers、0 retries，包含工作台类型检查和生产构建。覆盖既有明暗浮层、文件往返、历史、局部隔离及 390/768/1024/1440px 布局。
- 范围内 ESLint / Prettier、工具类型检查、Changesets 和差异检查通过。IDE 构建工具诊断能力有限，以实际类型检查与构建补证。

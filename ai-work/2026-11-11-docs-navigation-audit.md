# 文档导航与现行说明审计修复

## 问题现象

- 在 390×844 移动端首页点击“打开导航”，界面没有侧栏，也无法从该入口选择文档。
- README 仍称项目处于预览版；工作区架构仍描述构建期生成正文、示例占位和没有自动化测试；发布说明仍把 0.1.0/1.0 接入周期写成当前状态。
- `AGENTS.md` 的组件实现入口指向已经不存在的组件技能文件。
- 文档浮层测试把 TimePicker 的专用容器和样式承载层当作通用 Popover，面板实际已打开仍报失败。

预期：首页导航可打开、关闭与重开，选择文档后收起；现行说明与当前仓库实际结构一致，历史发布结果保留日期和适用范围。

## 根因

- Header 始终提供移动导航按钮，但 Layout 仅在非首页挂载 SidebarNavigation；首页更新 open 状态无法产生侧栏。
- 文档站转为本地维护正文、示例与静态资源后，通用架构说明没有同步；发布说明中的动态状态停留在早期迁移周期，组件技能删除后入口未更新。
- TimePicker 按固定基线使用专用 Tooltip 前缀；外层只负责定位，菜单阴影和圆角由内层 ScrollList 承载。原测试没有遵循此 DOM 契约，截图和 trace 确认面板实际可见；第一次仅修正外层选择器后，又准确暴露了样式层选错的问题。

## 修复方案

- 首页在显式打开时挂载导航，保留原有关闭事件与路由变化时收起的行为；非首页继续常驻侧栏结构。
- 新增正式生产态 Playwright 回归，覆盖首页打开、遮罩关闭、重开、选择介绍页后收起，并收集客户端异常与 console error。
- README 和发布手册以包清单、Changesets 状态与官方版本计划作为版本/模式来源，不记录未经本轮核对的 registry 状态。
- 发布审计顶部记录本轮本地事实：六包源码均为 `2.1.5`、不存在 `.changeset/pre.json`；保留原文件路径和下方带日期的历史证据。
- 工作区架构改为真实本地正文、Vue 示例、静态源码、索引生成与正式测试入口；组件实现入口改为现行组件契约。
- Theme Studio 说明将 Map 复用限定到实际使用索引的会话校验和 CSS 引用查找；色样解析仍有目录线性查找，本次仅校准措辞，不据未经测量的性能推断进行重构。
- 选择面板规格按各组件实际样式层定位，TimePicker 检查内层 ScrollList 的原有阴影与圆角，并新增外层无阴影断言；未改组件、阈值、固定等待或重试。

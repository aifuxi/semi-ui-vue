# Theme Studio 交互状态主题联动

日期：2026-11-08。

## 问题与根因

用户要求在全界面及弹层检查之后，继续核对各组件支持的悬浮、聚焦、选中和禁用状态，确保切换明暗模式及编辑全局样式时即时更新。

- 应用三组迭鹿预设，再把全局品牌改为 `#e8590c`，主按钮仍为 `rgb(91,90,247)`。预设生成的公开主色、链接、焦点和私有主按钮三态覆盖压住了品牌便捷设置；修改后实测为 `rgb(232,89,12)`。
- 禁用 Select 选项同时命中普通选项的独立前景绑定，呈现普通文字颜色。Checkbox / Radio 的禁用标签与说明也未接入独立禁用前景角色。
- 工作台原生链接的键盘轮廓读取 primary，未跟随独立 focus-border 编辑。

## 修复

- 统一全局编辑器、预览及弹窗的品牌更新入口。仅在用户实际编辑品牌时撤回仍等于原预设的相关覆盖，保留不同于预设的单项编辑、其他品牌、状态语义和圆角。直接导入、应用预设及复原保持原有文档语义。
- 普通选项绑定排除禁用和空选项，禁用 Select / Checkbox / Radio 接入对应禁用前景角色。工作台原生键盘入口使用全局焦点角色。
- 真实组件总览补充禁用复选框、单选框、开关、下拉选项，以及默认选中行、不可选行；通过组件公开 API 演示状态，不模拟 CSS class。
- 新测试以公开 JSON 下载/导入更新变量，保持预览组件实例、选中值和键盘焦点，覆盖浅→深→浅；按钮同时检查真实鼠标按下，禁用控件发送真实点击并验证值不变。

## 验证

# 使用文件驱动的 Vue 文档示例

组件文档中的每个可运行示例使用独立、可类型检查的 Vue 3 单文件组件，页面渲染与源码展示读取同一文件。静态示例优先服务端渲染，需要交互的示例按需激活；首期不引入浏览器内 Vue 编译器或在线编辑器，外部在线运行能力作为后续增强。

## Consequences

- 示例源码必须参与 TypeScript、构建和浏览器验证，Markdown 中不再维护一份容易漂移的重复实现。
- 文档页面通过统一示例容器提供预览、源码、复制和适用时的外部运行入口。
- 组件实现、示例渲染和源码展示共享同一事实来源，但文档示例不依赖内部对照工作台的页面协议。

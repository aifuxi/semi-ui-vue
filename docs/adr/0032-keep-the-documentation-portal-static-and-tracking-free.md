# 首期文档门户保持静态且无跟踪

首期组件文档门户不迁移 Slardar、Hornbill、内外网检测、Material、设计 iframe 或外部搜索，也不接入分析、监控、Cookie、用户标识和跨站跟踪。搜索、字体、图标、样式与正常浏览所需资源随静态产物提供；文档示例默认不向第三方发出请求。

## Consequences

- 站点无需 Cookie Banner，未来增加访问统计必须单独决定隐私告知、采样和数据保留策略。
- 只保留用户主动点击的 GitHub、npm 与上游 Semi Design 外链；远程媒体示例必须明确标注并提供可替代测试数据。
- 静态产物验证需要阻止意外引入分析脚本、未知第三方请求和核心 CDN 依赖。

# 使用按语言隔离的 Pagefind 静态搜索

组件文档门户使用 Starlight 内置的 Pagefind 生成静态搜索索引，不依赖外部搜索服务或服务器 API。搜索只返回当前语言中通过完成门槛的正式页面，索引页面标题、说明、章节、示例用途以及公开 API 名称和说明，同时排除大段示例源码正文。

## Consequences

- 中文和英文需要分别验证组件名、常见描述和 Prop 名能够命中对应语言页面。
- 开发中页面、内部覆盖清单和被排除的代码区域不能进入生产搜索结果。
- 静态发布产物必须包含完整 Pagefind 资源，并在普通静态文件服务器预览中验证搜索，而不能只在开发服务器判断可用。

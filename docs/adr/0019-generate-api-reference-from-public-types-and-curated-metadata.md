# 从公开类型与人工元数据生成 API 文档

组件 Props、Emits、Slots 和 Exposed API 的成员及类型以公开 TypeScript 契约为准，双语说明、默认值、版本和注意事项由结构化人工元数据维护。文档构建合并两者生成 API 表格，并在公开成员缺少说明、元数据指向不存在成员或内部类型意外进入公开表格时失败。

## Consequences

- MDX 页面负责使用指南、示例和补充说明，不再重复维护完整 API 表格。
- 生成器只遍历包的公开导出与明确登记的组件契约，不把运行时辅助类型或私有实现类型暴露给使用者。
- API 元数据需要双语成对维护，并与类型检查、文档构建和覆盖率审计共同进入质量门禁。

# 完整组件页面才能进入正式导航

组件文档可以按分类逐批迁移，但单个组件只有在双语页面成对、上游章节与示例逐项映射、公开 API 全覆盖、文件示例通过类型与浏览器验证、light/dark 和桌面/移动体验可用，并且链接、锚点与搜索完整后，才能进入正式导航。半成品页面保留在开发状态，不使用“待补充”或“即将支持”绕过门槛。

## Consequences

- 每个组件维护文档覆盖清单，所有上游章节和示例必须标记为已迁移或给出 React 专属、品牌、内部服务等明确排除理由。
- 导航数据只消费通过门槛的页面，开发中的页面仍可通过内部预览和直接地址验收。
- 文档构建和浏览器测试需要输出可审计的页面完成状态，不能只以构建成功代表内容完成。

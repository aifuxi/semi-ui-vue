# 组件门户首期包含完整基础指南

首期组件文档门户除全部完成的组件页面外，还包含双语首页、快速开始、导入与样式、TypeScript、主题与暗色模式、国际化、SSR、React→Vue 迁移总览、图标与插画、可访问性与浏览器支持以及组件总览。这些页面必须只描述已有代码与验证证据，不把未经验证的框架集成写成承诺。

## Consequences

- 首期完成不能只按组件页面数量判断，基础指南也必须成对翻译并进入链接、搜索和浏览器门禁。
- 首页是组件门户入口而非营销官网；设计原则、客户案例、生态市场、博客和营销内容留给未来完整官网门户。
- 公共安装、样式、SSR 和兼容性事实需要从发布包与现有验证结果生成或核对，不能从上游 React 文档直接复制。

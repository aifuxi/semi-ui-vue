# 保留独立品牌身份

项目使用 `Semi UI Vue` 名称和 `@aifuxi/*` 包身份，并说明这是基于 Semi Design v2.102.0 的独立 Vue 实现。组件视觉与行为对齐不表示官方隶属关系，不复用 Semi Logo、官方宣传 Banner 或客户案例作为本项目身份。

## Consequences

- README、静态说明和公开包保持独立品牌，不把品牌差异计为组件缺陷。
- 从上游改编的内容保留适用归属，并移除或改写会误导使用者的官方、内部服务和 React 专属宣传信息。
- 原文档站视觉、页脚和站点身份机制已随站点退役，不再作为开发与发布前置条件。

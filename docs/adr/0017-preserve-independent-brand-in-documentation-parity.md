# 文档体验对齐不复制 Semi 品牌身份

组件文档门户使用 `Semi UI Vue` 站点名称和 `@aifuxi/*` 包身份，在布局、排版、导航、主题和组件页面体验上对齐固定参考官网。站点不复用 Semi Logo、官方宣传 Banner、客户案例或会暗示官方隶属关系的链接，首期使用独立文字标识，并在项目介绍和页脚持续披露这是基于 Semi Design v2.102.0 的独立 Vue 实现。

## Consequences

- 视觉验收把文档体验与组件展示作为对齐目标，不把官方品牌资产的差异计为缺陷。
- favicon、社交分享图、站点标识和 SEO 身份必须由本项目独立提供。
- 从上游迁移的内容需要移除或改写品牌、客户、内部服务和 React 专属宣传信息。

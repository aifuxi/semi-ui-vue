# 使用显式双语前缀与上游兼容的文档路由

组件文档门户使用 `/zh-CN/<category>/<page>` 与 `/en-US/<category>/<page>` 作为正式 URL，并沿用固定参考官网的分类层级。根路径固定跳转到 `/zh-CN/`；语言切换保留当前逻辑页面，简写或旧地址只提供重定向，不成为新的正式 URL。

## Consequences

- 每个正式主题必须同时提供中文和英文页面，构建检查把缺少任一语言版本视为错误，不依赖 Starlight 的内容回退掩盖缺口。
- 内容文件在两种语言中保持一致的相对路径，以便语言切换、搜索和覆盖率审计建立稳定映射。
- 分类路径优先保持与 Semi Design v2.102.0 内容结构一致，未来扩展首页、设计与生态内容时无需重新设计语言路由。

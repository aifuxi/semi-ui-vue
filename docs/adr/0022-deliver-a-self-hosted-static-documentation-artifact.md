# 交付自托管的静态文档产物

组件文档门户构建为部署在域名根路径的静态产物，仓库负责构建、链接、搜索、双语和浏览器验证，但不使用 GitHub Pages，也不自动连接云服务器。`semi.fuxiaochen.com` 的 DNS、TLS、服务器上传与启用由项目所有者在仓库外完成。

## Consequences

- 仓库和 CI 不保存云服务器地址、SSH 凭据或部署密钥，也不在主分支更新时自动上线。
- 发布产物以 `https://semi.fuxiaochen.com` 为正式站点源并使用根路径资源地址，部署前仍需在隔离静态服务器中预览验证。
- 首期只交付通用静态目录及其完整性证据，不附带 Nginx、Caddy、Docker、SSH 或云厂商配置。
- 服务器软件、缓存、压缩、安全响应头和旧 URL 重定向属于仓库外部署责任；站点不能依赖某一种服务器的专有行为才能工作。

# 首期只发布一个活动文档版本

组件文档门户首期只维护当前组件库发布线，正式页面不增加 `/v1/` 或其他版本前缀。站点同时显示当前 `@aifuxi/*` 版本和固定参考基线 Semi Design v2.102.0；组件库仍处于预发布阶段时必须展示清晰的预览版提示。

## Consequences

- 文档内容随当前活动发布线更新，不维护历史版本选择器或多份内容树。
- 组件库版本与参考基线版本使用不同标签和文案，不能把两者合并成一个模糊版本号。
- 只有未来需要同时维护两个不兼容的稳定发布线时，才另行决定版本化 URL、归档和搜索隔离策略。

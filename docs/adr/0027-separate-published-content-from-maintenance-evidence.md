# 分离公开文档内容与维护证据

正式双语 MDX、Vue 示例和 API 元数据由 `apps/docs` 拥有，仓库级 `docs/components/<component>/` 只保留对齐矩阵、文档覆盖清单和其他维护证据。现有组件 `index*` 与 `react-to-vue.md` 的有效用户内容迁入正式页面后删除原重复副本，不建立两套可独立修改的用户文档。

## Consequences

- 公开页面不能在运行时读取维护者对齐矩阵，内部证据也不默认进入搜索或站点导航。
- 文档应用使用 Starlight 的常规内容目录，避免仅为保留旧目录结构而维护自定义内容加载管线。
- React→Vue 组件迁移说明属于用户内容，需要进入正式双语页面；源码证据、排除理由和覆盖状态仍留在维护证据中。

# 文档视觉使用上游对照与本站回归两层证据

组件文档门户对代表页面的顶部导航、侧栏、内容宽度、排版、主题、示例容器、代码区和 API 表格执行关键样式与几何的上游对照，同时为 Semi UI Vue 独立站点建立整页视觉与交互回归基线。品牌标识、官方宣传内容以及 Starlight 必需的可访问 DOM 差异属于预先定义的非对齐范围，不通过大面积 mask 隐藏其他偏差。

## Consequences

- 代表页面至少覆盖首页、组件总览、普通组件、Portal 组件、复杂表格、图标资源和长 API 页面。
- 整页回归覆盖桌面 `1440×900` 与移动 `390×844`、zh-CN/en-US、light/dark；其余正式页面执行路由、链接、锚点、溢出和基础交互 smoke。
- 键盘导航、焦点可见性、跳转链接、ARIA 与 reduced-motion 作为独立验收维度，不能仅由截图证明。

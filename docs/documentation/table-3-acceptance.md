## 断言与审阅

复用 Table 第二批的完整 DOM/class/属性/控件 property、computed style、0.5 CSS px 几何及 threshold 0.1 / maxDiffPixelRatio 0.001 像素门槛。使用完整目标裁剪和真实有限动效终态；Portal 保留绝对视口位置，截图前后检查视口、滚动与目标几何未改变。交互样式完整无损 gzip，default-styles 保留原始 JSON；不忽略可见节点或降门槛。

每个适用场景覆盖真实主要操作，双语 light/LTR 覆盖源码、重置和在线编辑运行。虚拟列表必须使用真实窗口、滚动终态与行内容断言，不能以静态全量渲染替代。

Table 文档页同时挂载 Dynamic。采集其它示例前也先观察它完成首次异步请求（8 行、首条 0.fig、loading 消失），避免截图期间整页高度改变；不使用固定延时。虚拟列表默认行高 53，未测量后缀按固定 react-window 的 50 估算，测量缓存跨筛选缩短与恢复保留；窗口内节点和总高度均参与断言。

Dynamic 固定表头及边框开关保留未传 checked 的初态；固定表头关闭时移除受控 checked。矩阵分别检查原生 checked 与完整 ARIA 属性，不将缺省状态强制转为 false。

Dynamic 的排序请求与最终状态分别认证：固定回调返回完整查询列，首次 sorter 带回 filteredValue=[]，之后该列作为受控空筛选出现在 filters 中。示例先合并 sorter 再合并 filters，降序请求因此被旧筛选列覆盖回升序。每列依次请求 ascend/descend/descend，最终大小列始终 ascend；日期列首次操作后两列同时 ascend。首次请求后行键为 0,40,1,41,2,42,3,43，后两次为 32–39。矩阵逐次检查原回调、loading 开始与结束、每列 ARIA/箭头及全部行键，再做完整视觉对照；其余示例保持通用三态排序断言。该状态链另由只读 React 参考观察确认。

分组表头按各层实际列集计算固定偏移及边缘，父组不自动补 rowSpan，叶子仍补足跨层高度；FullRender 标题回调中的 selection 保留组件提供的包裹节点。固定列展开内容使用根容器实测宽度扣除固定单元格内边距、边框和实际滚动条宽度，挂载后开启固定列同样安装测量与尺寸观察。表格固定布局依据声明列与固定表头条件决定，注入固定选择或展开列不单独改变整表布局。虚拟列表程序定位在新窗口提交 DOM 后写入滚动位置，避免尾部目标被旧总高截断；连续请求与卸载清理由公开回归覆盖。

固定公开入口在 resizable 的真假切换时重建内部 Table；Vue 同样以模式为 key 重建私有实例，重新初始化非受控状态并清理旧观察器、虚拟缓存、浮层与伸缩监听。受控值仍由当前 props 决定，同一开启状态下修改配置不重建。矩阵保留先选择、隐藏选择列再开启伸缩的完整前序路径，避免旧选择状态泄漏。

正文补充固定动态示例的异步与开关边界；Vue 事件、VNode、Table.Column 和虚拟列表 ref 继续按公开类型描述。展开渲染对象在组件边界解包 children，并以独立公开回归验证折叠重开。最终语义审阅、类型与低成本检查完成后冻结映射指纹，再由主调度执行代表诊断、preflight 和正式矩阵。证据产生后不回写本文件或旧报告指纹。

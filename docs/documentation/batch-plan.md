- ScrollLoad 尚未就绪：固定双语片段在函数式 setDataSource 内递增 countRef，并调用 setLoading/setHasMore。2026-09-13 接入真实依赖后的中文只读观察得到每次追加 5 行、标题段依次为 0–4、10–14、20–24……90–94，按钮在第 2、4……10 次请求完成后出现，空结果请求后共 50 行。该观察暴露了计数与按钮门槛差异，不是有效验收：代表诊断未通过，独立观察也在耗尽后的再次加载断言失败。继续前须解释该运行序列与固定更新逻辑的关系，并核对双语及构建模式，不能直接用预想的连续 100 行、每四批门槛改写断言，或把一次观察提升为已确认契约。Vue 另有双语文案、Spinner 层级与按钮区域高度差异。
- Virtualized 已有真实窗口计算与异步加载，并非全量渲染或按钮模拟；但 Vue 渲染 Skeleton 而固定片段在缺数据时返回空行，加载区间/并发策略、List.Item 定位层级、AutoSizer 测宽及双语正文仍需局部对齐。先验证首批、连续/快速跳滚、返回已加载区间、末行与宽度变化，不扩建公开 List API。
